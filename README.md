# 🖥️ Jarvis Desktop Widget

基于 MiniMax M2.7 模型的 AI 桌面小工具集合。

## 功能

- 🕐 **实时时钟** - 显示当前时间和日期
- 🌤️ **天气显示** - Saskatoon 天气信息
- 📰 **新闻订阅** - 世界/中国/科技新闻分类
- ✅ **待办清单** - 本地存储的待办事项
- 🔢 **计数器** - 可调节的数字计数器
- 🔍 **快捷搜索** - 一键 Google 搜索

## 使用方法

直接打开 [index.html](index.html) 即可使用。

## 技术栈

- HTML5 + CSS3 + JavaScript
- 无需后端，纯前端实现
- LocalStorage 存储待办数据
